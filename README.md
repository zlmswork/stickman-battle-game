# Stickman Battle Game

A small browser game built with HTML, CSS, and JavaScript.

## How to Play

Open `index.html` in a browser.

- Move: `A` / `D` or arrow keys
- Jump: `W`, up arrow, or space
- Dash: `Shift`
- Attack: `J`

## Files

- `index.html` - page structure
- `style.css` - visual styling
- `game.js` - game logic
